# Kedai Sidikalang: Profil dan Katalog (Proyek, tahap 1)

Usaha rekaan di Medan. Berkas: `index.html`, `style.css`, `script.js`, `CATATAN-AI.md`.

## Menjalankan
Buka folder di Visual Studio Code, klik kanan `index.html`, pilih Open with Live Server, atau buka langsung di Chrome.

## Yang wajib diganti di script.js
`wa` (format 62812..., tanpa + dan tanpa 0), `instagram`, `facebook`, `tiktok`.
Alamat, jam buka, dan nama kelompok diganti langsung di `index.html`.

## Git (mulai Sesi 6)
```
git init
git add index.html
git commit -m "Tambah kerangka HTML5 semantik beranda"
git add style.css
git commit -m "Tambah gaya tema kedai kopi"
git add script.js
git commit -m "Tambah katalog, pencarian, dan tautan WhatsApp"
git add CATATAN-AI.md README.md
git commit -m "Tambah catatan pemakaian AI dan README"
git branch -M main
git remote add origin <URL-repositori>
git push -u origin main
```
